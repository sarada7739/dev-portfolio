# T-031 制作物のローカル編集ツール（tools/admin）
難易度: L2 / 担当: impl-l2 / NGカウンタ: 0（続行）
監査ゲート: 対象（ファイルアップロード・ファイル書き込み・git 実行）

## 目的
ユーザーが Claude を介さず、制作物カードの追加・編集・並べ替え・削除と公開（push）を GUI で行えるようにする。

## 参照
- docs/architecture.md「ローカル編集ツール」節（方針）
- src/data/works.json、src/data/types.ts の Work（slug, title, titleMasked?, description, year, thumbnail, href, image?, github?）
- 既存素材の作り方: archive/tasks/T-024.md, T-026.md（サムネ 1200×720 / 拡大用 JPEG 品質 85）

## 構成
- tools/admin/server.mjs: Node 標準モジュールのみ（http, fs/promises, path, crypto, child_process）。依存追加禁止
- tools/admin/index.html（+ 必要なら app.js / style.css）: 素の HTML/CSS/JS。ビルド不要。外部 CDN 禁止
- package.json に `"admin": "node tools/admin/server.mjs"` を追加
- 起動時に URL（トークン付き）をコンソールに表示し、既定ブラウザで開く（開けなくても URL 表示で可）

## 受入条件 — サーバー
- [x] 127.0.0.1 の固定ポート（4319、使用中なら次の空き）だけで待ち受ける
- [x] 起動ごとに crypto.randomBytes(32) のトークンを生成。ページは `/?token=...` でのみ配信し、API は `X-Admin-Token` ヘッダ一致を必須にする（不一致 403）
- [x] Host ヘッダが `127.0.0.1:<port>` / `localhost:<port>` 以外は 403。Origin ヘッダがあり自サーバー以外なら 403
- [x] API: GET /api/works（works.json を返す）、PUT /api/works（配列全体を保存）、POST /api/images（slug と thumbnail/full の JPEG を base64 で受け取り public/images/works/<slug>.jpg と <slug>-full.jpg に書く）、POST /api/publish
- [x] slug は `^[a-z0-9]+(-[a-z0-9]+)*$` のみ許可。書き込み先パスは slug からだけ組み立て、resolve 後に public/images/works/ 配下であることを確認
- [x] リクエストボディ上限 20MB。JPEG はマジックバイト（FF D8 FF）を確認
- [x] PUT /api/works はサーバー側で検証: 配列、各要素に slug/title/description/year/thumbnail/href が文字列で存在、slug 重複なし、github/href が空・"#"・https:// のいずれか。不明なキー（titleMasked 等）は保持する。保存は 2 スペースインデント + 末尾改行（既存書式と同じ）
- [x] カード削除時、そのカードの thumbnail / image が `/images/works/` 配下で他カードから参照されていなければファイルも削除
- [x] POST /api/publish: `git commit -m "works: <要約>" -- src/data/works.json public/images/works` → `git push origin main` を execFile（シェル不使用）で実行し、stdout/stderr を返す。変更が無ければその旨を返す。他のファイルの変更はコミットしない
- [x] 例外を握りつぶさない。エラーはステータスと短いメッセージで返す

## 受入条件 — 画面
- [x] 一覧: 現在のカードをサムネ付きで表示。上下ボタンで並べ替え、編集、削除（確認ダイアログ）
- [x] 追加・編集フォーム: タイトル、説明、年（既定 "Y" + 今年）、GitHub URL（任意）、リンク URL（任意、空なら "#"）、slug（タイトルから自動提案・編集可）
- [x] 画像: ファイル選択またはドラッグ&ドロップ（png/jpg/webp）。5:3 固定の切り抜き枠をドラッグで移動・角でサイズ変更でき、プレビューを表示。保存時に canvas で サムネ 1200×720 と 拡大用（長辺 2000 を超える場合のみ縮小）を JPEG 品質 0.85 で生成して POST /api/images
- [x] 編集時に画像を差し替えなければ既存画像はそのまま
- [x] 「公開」ボタン: 確認ダイアログ後に /api/publish を呼び、結果（成功/失敗と git の出力）を表示
- [x] 日本語 UI。見た目は簡素でよい（V0）
