# T-022 リンク未指定の制作物カードはクリックで画像を拡大表示
難易度: L1 / 担当: impl-l1 / NGカウンタ: 0（続行）

## 目的
ユーザー指示: 「その他の制作物」で URL を指定していないカードは、クリックで画像を拡大表示する。

## 参照
- src/components/ui/WorkCard.tsx（現在は全体を `<a href={work.href}>` で包む）
- src/data/types.ts（Work）、src/data/works.json
- 拡大用素材（配置済み）: public/images/works/wanwan-full.jpg（1360×768）、orrery-full.jpg（1920×1032）
- docs/constraints.md（キーボード操作、alt、dangerouslySetInnerHTML 禁止）
- 共通ルールは archive/tasks/T-004.md の「共通ルール」節と同じ。ライトボックスのみ `"use client"` 許可

## 受入条件
- [x] `Work` 型に任意項目 `image?: string`（拡大用）を追加。works.json の wanwan に `/images/works/wanwan-full.jpg`、orrery に `/images/works/orrery-full.jpg` を設定。他6件は未設定（拡大時は thumbnail を使う）
- [x] `href` が `#` または空のカードは `<a>` でなく `<button type="button">` にし、クリックでライトボックスを開く。`href` が有効なカードは従来どおり `<a>`（外部なら `target="_blank" rel="noopener noreferrer"`）
- [x] `src/components/ui/Lightbox.tsx`（`"use client"`）: ネイティブ `<dialog>` を使う。開くと画像（next/image、`alt` はカードと同じ）を画面中央に最大 `max-w-content`・高さはビューポート内に収める。背景は `bg-ink/80`（トークン + 不透明度修飾子は可）。閉じる手段: 右上の × ボタン（`aria-label="閉じる"`）、背景クリック、Esc。開いている間は本文スクロールを止める
- [x] `"use client"` は Lightbox と、それを開くトリガー（WorkCard の button 部分）に限る。WorkCard 全体を client にしてよいが、Works.tsx / page.tsx は Server Component のまま
- [x] キーボードのみでカードにフォーカス → Enter で開く → Esc で閉じるまで操作でき、閉じた後フォーカスがカードに戻る
- [x] 生の px / hex / 任意値なし。アニメーションは入れない（Tailwind 既定の `transition` 程度は可）
- [x] `pnpm lint` / `pnpm build` / `pnpm test` が通る。1440px でクリック → 拡大 → Esc を dev サーバーで確認（CDP または内蔵の方法。ヘッドレスは自分の PID のみ終了）
