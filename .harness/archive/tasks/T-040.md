# T-040 粒子の輪の慣性と立体波
難易度: L3 / 視覚忠実度: V2 / 担当: メイン（利用者指定） / NGカウンタ: 0

## 受入条件
- 触れた表面付近からドラッグに追従し、リリース時の速度を引き継いで減速する。
- 波は輪に沿って両方向と裏側へ伝わり、3次元で点を変位させる。
- 現行の丸い粒・配色・操作文なしの外観を保ち、アニメーションを画面更新に同期する。
- 参照はT-039の静止画と実装。タッチ入力、縦スクロール、キーボード、停止、低モーション、WebKitでの動作と変更前後の速度を確認する。

## 検証
- メインのGPT-6.2 Astra（ultra）が実装・確認。単体テスト4件で前面の選択、曲面の継ぎ目、奥行き変位と到達差、ドラッグの先行・慣性減衰を検証。既存7件を含む11件、lint、型検査、本番ビルドが成功。
- Windows版Playwright WebKit、タッチ・440×956 CSS px・DPR 3の同条件で2.6秒ずつ描画回数を計測。旧20.9fps、新40.6fps。Chromiumは21.6fpsから60.0fps。iPhone実機の計測は未実施。
- ブラウザ入力でクリック、タップ、横ドラッグ、キー操作の描画差を確認。縦スワイプは93pxスクロールして余計な画素差0。両エンジンでGPUコンテキスト喪失・2D描画・低モーションと静止画を確認。
- 証跡は docs/reference/shots/t040-{before,after}-bench.json、t040-after-webkit.png、t040-lighthouse.json。
