## 受入条件
- [x] `@opennextjs/cloudflare` を devDependencies に追加し、`open-next.config.ts` と `wrangler.jsonc`（name "dev-portfolio"、`compatibility_date` は追加日、`compatibility_flags: ["nodejs_compat"]`、`main` と `assets` は公式手順どおり）を作成
- [x] `package.json` に `"preview": "opennextjs-cloudflare build && opennextjs-cloudflare preview"` と `"deploy": "opennextjs-cloudflare build && opennextjs-cloudflare deploy"` を追加。既存の `build` は変えない
- [x] CI に `pnpm exec opennextjs-cloudflare build` のステップを追加し、Linux 上で OpenNext ビルドが検証される（ローカル Windows では symlink EPERM で失敗するため受入条件から除外。decisions.md 参照）
- [x] `public/_headers` または wrangler 設定で、`/api/*` にキャッシュさせない（公式推奨に従う。不要なら理由を報告）
- [x] `.github/workflows/ci.yml`: `push`（main）と `pull_request` で起動。Node 22 + pnpm（`pnpm/action-setup`、`actions/setup-node` の cache pnpm）。ジョブは順に `pnpm install --frozen-lockfile` → `pnpm lint` → `pnpm test` → `pnpm build` → `pnpm audit --audit-level high`。デプロイはしない（Cloudflare の Git 連携に任せる）
- [x] `pnpm audit --audit-level high` がローカルで 0 件であること。出たら報告して止まる（依存の入れ替えは判断が要るので実装しない）

- [x] `.gitignore` に `!.env.example` を追加（`.env*` に巻き込まれている。監査の軽微指摘）
- [x] `docs/architecture.md`「デプロイ手順」のビルドコマンドを実際に動いたコマンドに合わせて修正
