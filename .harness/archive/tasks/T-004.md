## 共通ルール（T-004〜T-008 共通）
- 生の px / hex / フォント名を書かない。Tailwind の `@theme` トークン（`bg-cream` `text-ink` `font-serif` `text-display` `rounded-pill` `shadow-card` `max-w-content` 等）のみ使う
- コンポーネントは Server Component。`"use client"` はフォーム以外で使わない
- 画像は next/image。装飾画像は `alt=""`
- セクションには `id` を付け、ナビのアンカーにする（制作物 → `#works`、一覧 → `#works-all`、お問い合わせ → `#contact`）
- page.tsx はセクションを順に並べるだけ。ロジックを持たない
