## 目的

## 受入条件
- [x] `src/data/site.json` と `SiteMeta` 型に `url`（既定 "https://example.com"。本番URL確定後に差し替え）、`title`（「しずかな道具を、しずかなふたりへ。｜個人開発」）、`description`（product.md の概要を 80〜120 文字で要約）を追加
- [x] `src/app/layout.tsx` の `metadata` を `site` から生成: `metadataBase: new URL(site.url)`、`title`、`description`、`openGraph`（title / description / url / siteName / locale "ja_JP" / type "website" / images）、`twitter`（card "summary_large_image"）、`alternates.canonical` "/"
- [x] OGP 画像: `src/app/opengraph-image.tsx` で `ImageResponse` を使って 1200×630 を生成（背景 cream、中央に tagline 2行を serif 風、下に sub）。フォントは next/font が使えないので、システムフォントか `fetch` で Google Fonts の woff を読み込む（読み込みに失敗したらフォールバックで生成を止めない）
- [x] `src/app/sitemap.ts` で `/` のみを返す。`src/app/robots.ts` で全許可＋sitemap の URL
- [x] `src/app/layout.tsx` の `<html lang="ja">` を維持。`viewport` は Next.js 既定でよい
- [x] `pnpm build` の出力に `/opengraph-image` `/sitemap.xml` `/robots.txt` が現れる
- [x] `pnpm lint` / `pnpm build` / `pnpm test` が通る
