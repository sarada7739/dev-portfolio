## 目的
フッター（参照画像 y=1230〜1360px）と、参照画像に無い問い合わせフォームの UI を作る。
送信先 API は T-009 で作るので、ここではフォームの見た目・クライアント検証・送信状態表示まで。

## 受入条件
- [x] `zod` を dependencies に追加。`src/lib/contact-schema.ts` に `contactSchema` を export: name 1〜100文字、email は `z.email()`（または `.email()`）、message 1〜2000文字、turnstileToken 1文字以上。`ContactInput` 型も export
- [x] `@marsidev/react-turnstile` を dependencies に追加。`.env.example` の `NEXT_PUBLIC_TURNSTILE_SITE_KEY` 行の直下に、Cloudflare 公式のテスト用 Site Key `1x00000000000000000000AA`（常に成功）をコメントで案内する1行を追加
- [x] `src/components/sections/Footer.tsx`（Server Component）: `id="contact"`、`bg-cream-deep`、上下余白 `py-section-sm lg:py-section`。中央寄せで、見出し「ご一緒に、ものづくりを。」（`font-serif text-h2 text-ink-soft`）→ ContactForm → メール（`site.email` を `mailto:` リンク、`text-small text-ink underline underline-offset-4`）→ social（`site.social` を横並び、`text-caption tracking-wide text-gray-light`、外部リンクは `rel="noopener noreferrer" target="_blank"`）→ copyright（`text-caption text-gray-faint`）
- [x] `src/components/ui/ContactForm.tsx`（`"use client"`）: 氏名・メール・本文（textarea）の3フィールドと送信ボタン（既存 Button と同じ見た目。`<button type="submit">` なので Button を拡張するか、同じクラスで書く）。幅は最大 480px 相当のトークン（`max-w-md` 等の既定スケール可）。入力枠は `border border-line rounded-card bg-card text-body`、フォーカス時 `border-ink`
- [x] クライアント検証: 送信時に `contactSchema.safeParse` で検証し、エラーはフィールド直下に `text-caption text-coral-text` で表示
- [x] Turnstile ウィジェットを本文の下に配置。`siteKey` は `process.env.NEXT_PUBLIC_TURNSTILE_SITE_KEY`。トークンを state に保持
- [x] 送信: `fetch("/api/contact", { method: "POST", headers: { "Content-Type": "application/json" }, body })`。送信中はボタン無効化、成功時は「送信しました。返信をお待ちください。」、失敗時は「送信できませんでした。時間をおいて再度お試しください。」を `text-small` で表示。API は未実装なので現時点では失敗表示になってよい
- [x] フォーム直下に1行: 「いただいた情報は返信のためにのみ使用し、それ以外の目的には使いません。送信時に Cloudflare Turnstile と Resend を利用します。」（`text-caption text-gray`）
- [x] すべての input に `<label>` を関連付け、キーボードのみで送信ボタンまで到達できる
- [x] `src/app/page.tsx` の HowIWork の直後に Footer を追加
- [x] 1280px と 375px で崩れない。`pnpm lint` と `pnpm build` が通る
