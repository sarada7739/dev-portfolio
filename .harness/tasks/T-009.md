# T-009 /api/contact Route Handler
難易度: L2 / 担当: impl-l2 / NGカウンタ: 0 / 監査ゲート: 対象（個人情報の送信）

## 目的
フォーム送信を受け、Turnstile 検証 → Resend で自分宛にメール送信する。状態を持たない。

## 参照
- docs/architecture.md「フォームの境界」「環境変数」
- docs/constraints.md「機微データ」「入力検証」（すべて機械的に検証される）
- src/lib/contact-schema.ts（T-008 で作成。サーバー側でも同じスキーマを使う）
- .env.example

## 受入条件
- [ ] `resend` を dependencies に追加
- [ ] `src/app/api/contact/route.ts` に `POST` を export。`runtime` は指定しない（OpenNext が Workers で動かす。Node 専用 API を使わない）
- [ ] Content-Type が `application/json` でなければ 415
- [ ] `contactSchema.safeParse` で検証し、失敗なら 400 と `{ error: "invalid_input" }`。フィールド別の詳細メッセージは返さない（入力値をレスポンスに反映しない）
- [ ] Turnstile 検証: `https://challenges.cloudflare.com/turnstile/v0/siteverify` に `secret` と `response` を POST。`success` が false なら 403 と `{ error: "turnstile_failed" }`
- [ ] Resend で送信: `from` は Resend の検証済みドメインまたは `onboarding@resend.dev`（環境変数 `CONTACT_FROM_EMAIL`、既定 `onboarding@resend.dev`）、`to` は `CONTACT_TO_EMAIL` のみ（ユーザー入力を宛先・cc・bcc に使わない）、`replyTo` に送信者 email、`subject` は固定文字列「[ポートフォリオ] お問い合わせ」
- [ ] メール本文はプレーンテキスト。name / email / message を含める際、`\r` `\n` を name と email からは除去する（ヘッダインジェクション対策）。message の改行はそのまま
- [ ] 成功で 200 と `{ ok: true }`。Resend 失敗で 502 と `{ error: "send_failed" }`
- [ ] ログ出力は `console.error` でエラー種別（"turnstile_failed" / "send_failed" 等）と HTTP ステータスのみ。name / email / message / トークンをログに出さない
- [ ] 環境変数が未設定（`RESEND_API_KEY` / `CONTACT_TO_EMAIL` / `TURNSTILE_SECRET_KEY`）なら 500 と `{ error: "misconfigured" }`。どの変数かはログにのみ出す
- [ ] `.env.example` に `CONTACT_FROM_EMAIL=` を追加
- [ ] `src/app/api/contact/route.test.ts` を Vitest で作成: 415 / 400（name 101文字・不正 email・message 2001文字）/ 403 / 200 / 502 の各ケース。`fetch` と Resend はモック。`vitest` を devDependencies に追加し `pnpm test` で実行できる
- [ ] `pnpm lint` / `pnpm build` / `pnpm test` が通る
