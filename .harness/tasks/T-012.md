# T-012 全体の視覚突合とレスポンシブ最終調整
難易度: V2 / 担当: ui-reviewer（判定）→ impl-l1（修正）/ NGカウンタ: 0

## 目的
参照画像と実装を並べて突合し、具体値で差異を洗い出して直す。「なんとなく違う」は禁止。

## 参照
- docs/reference/lp-reference.jpg（768×1360。デスクトップ 1440px 想定を ×0.533 で縮小したもの）
- docs/design-tokens.md（値の唯一の出典）
- 撮影手段: `"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --screenshot=<out.png> --window-size=1440,2600 --hide-scrollbars http://localhost:3000`（`pnpm dev` または `pnpm start` を起動しておく）。375px はモバイル幅 `--window-size=375,4000`
- 撮影結果は `docs/reference/shots/` に保存（`.gitignore` に追加し、コミットしない）

## 手順
1. ui-reviewer が 1440px と 375px で撮影し、参照画像と並べて突合する
2. 差異を具体値（参照 Xpx 相当に対し実装 Ypx）で列挙し `視覚判定: 続行 / NG` を出す
3. NG なら impl-l1 が差異一覧だけを直し、再撮影 → 再判定。NG カウンタはロジック NG と合算
4. 最終確認はユーザーの目視に委ねる旨を判定に明記する

## 受入条件
- [ ] 1440px と 375px のスクリーンショットが撮れている
- [ ] ui-reviewer の `視覚判定: 続行`（差異が無いか、残差が具体値で許容と明記されている）
- [ ] 375px で横スクロールが出ない（`document.documentElement.scrollWidth <= 375`）
- [ ] 修正が入った場合、トークン以外の値を使っていない（必要ならトークン追加＋design-tokens.md 追記）
- [ ] `pnpm lint` / `pnpm build` / `pnpm test` が通る
