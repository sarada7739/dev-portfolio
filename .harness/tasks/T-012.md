## 手順
1. ui-reviewer が 1440px と 375px で撮影し、参照画像と並べて突合する
2. 差異を具体値（参照 Xpx 相当に対し実装 Ypx）で列挙し `視覚判定: 続行 / NG` を出す
3. NG なら impl-l1 が差異一覧だけを直し、再撮影 → 再判定。NG カウンタはロジック NG と合算
4. 最終確認はユーザーの目視に委ねる旨を判定に明記する
