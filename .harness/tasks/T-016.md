# T-016 フォーム失敗時に Turnstile をリセットする
難易度: L1 / 担当: impl-l1 / NGカウンタ: 0

## 目的
Turnstile のトークンは1回限り。送信失敗後に再送すると使用済みトークンで 403 になるため、失敗時にウィジェットをリセットして新しいトークンを取り直す。

## 参照
- src/components/ui/ContactForm.tsx
- @marsidev/react-turnstile の `ref` と `reset()`（node_modules/@marsidev/react-turnstile の README / 型定義で確認）

## 受入条件
- [ ] `Turnstile` に `ref` を渡し、送信が失敗（非 2xx または fetch 例外）したら `ref.current?.reset()` を呼び、`turnstileToken` state を空に戻す
- [ ] 送信成功後もリセットし、二重送信を防ぐ（成功メッセージは維持）
- [ ] `expired-callback`（`onExpire`）でトークン state を空に戻す
- [ ] 失敗メッセージを「送信できませんでした。もう一度お試しください。」に変更（「時間をおいて」は不要になるため）
- [ ] `pnpm lint` / `pnpm build` / `pnpm test` が通る
