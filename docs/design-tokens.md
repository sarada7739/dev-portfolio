# ポートフォリオのデザイントークン

Refero に掲載された Dala の画面から、黒い余白、大きな細身の文字、紫の操作ボタンを採用した。トップでは丸い光点を奥行きのある輪に並べる。[参照ページ](https://styles.refero.design/style/e5f5f8cf-e68d-4ed1-bbf5-6b67569af648)

## 色と面

| 用途 | 色 |
| --- | --- |
| 全体の背景 | 黒 `#000000` |
| 見出し・本文 | 白 `#ffffff`、補助文 `#bdbdbd`、メタ情報 `#a3a3a7` |
| 主な操作 | 紫 `#8052ff`、白文字 |
| 著者名 | 琥珀 `#ffb829` |
| 粒子 | 翡翠、氷色、水色、薄紫に少量の淡い桃色。手前に明るい芯を置く |
| 入力・区切り | 面 `#101012`、罫線 `#303034` |
| キーボードフォーカス | ライラック `#c8b5ff` |

## 文字と余白

- 見出しの欧文は自前配信の Geist、ウェイト400。日本語は端末のゴシック体を使う。
- ヒーローの文字はスマホで約60px、デスクトップで最大112px。字間は約−0.065em、行間は0.95。
- セクション名は36〜68px、作品名は24〜32px。日本語本文は15〜18px、行間は1.7〜1.9。
- 余白は6・12・18・24・36・60・96・120pxを基準にする。本文の最大幅は1280px。
- 主要な操作は高さ44px以上のピル、写真は18〜24pxの角丸。通常のセクションに影は付けない。
- 右に粒子、左に本人の肩書きと紹介を配置。小画面は紹介と粒子を縦に並べる。
- 作品写真と詳細を余白で分け、一覧は2列、640px未満は1列。ナビは狭い幅で開閉式にする。

## 粒子と動き

- 丸い光点に大小と明暗をつけて、ねじれた輪の陰影を作る。強い光は限られた粒に添える。
- 最初のフレームを画像で配信し、Canvas 2D が使える端末で同じ構図を動かす。
- クリック・タップで触れた位置から波が広がる。ドラッグで向きを変え、タッチの縦スクロールとピンチズームを保つ。動きを減らす設定では静止画を表示する。
- 画面外または非表示タブでは描画を止める。本文と操作は初回から読める。

## 過去版

生成りのクラシック版とシアンのネオン版は、それぞれの改訂時点の配色・書体の系統・写真・レスポンシブレイアウトで保存する。
