# product.md — 何を作るか

## 概要
個人開発者のポートフォリオLP（1ページ）。主力プロダクト Nisoine を看板に据え、
訪問者から仕事の相談を受けることを目的とする。

## 利用者
- 主: クライアント候補（受託・業務委託の依頼を検討している人）
- 副: 採用担当者、Nisoine に興味を持った一般ユーザー

## 利用者が今困っていること
- 開発者の実績・技術・仕事の進め方を、1画面で静かに把握したい
- 連絡手段が散らばっていて、どこから相談すればよいか分からない

## 提供するもの
1. ヒーロー — コピーと「制作物を見る」CTA
2. Nisoine セクション — 主力プロダクトの紹介（写真・アプリ画面・技術タグ）
3. その他の制作物 — 8件のカードグリッド（データは JSON で分離、初回はプレースホルダ）
4. HOW I WORK — AI活用の姿勢を4項目で
5. フッター — 問い合わせフォーム、メール、SNSリンク

## 完成の定義（初回リリース）
- [ ] 参照画像（docs/reference/lp-reference.jpg）に忠実な1ページが、デスクトップ・スマホ両方で崩れず表示される
- [ ] 問い合わせフォームの送信内容が自分のメールアドレスに届く
- [ ] Cloudflare Pages に公開され、独自URLでアクセスできる

## 初回リリースに含めないもの
- 「事例を読む」の遷移先（Nisoine 詳細ページ）
- 多言語対応
- ブログ・ノート機能
- 制作物の実素材（写真・スクショ）。差し替えは別タスクで行う
